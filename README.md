# HAVE

HAVE è una web app mobile-first per gestire collezioni di carte collezionabili e trovare scambi compatibili.

## Obiettivo MVP
- Fotografia di una pagina del raccoglitore
- Riconoscimento carta per carta
- Identità precisa: gioco, set, numero, rarità, lingua, variante
- Collezione, doppioni e wishlist
- Valori da più fonti con fonte e timestamp sempre visibili
- Stima HAVE calcolata in modo trasparente
- Matching automatico degli scambi

## Stato attuale
La prima base funzionante include interfaccia mobile, acquisizione foto, riconoscimento demo, collezione locale, scheda carta e valori demo.

I dati di mercato reali e il riconoscimento automatico reale verranno collegati nelle prossime iterazioni.
